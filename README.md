# Lazy Entry - 就活フォーム自動入力拡張機能

就職活動や転職活動のエントリーシート（ES）入力、面倒くさくないですか？
「Lazy Entry」は、あなたのプロフィール情報を保存し、あらゆる求人サイトの入力フォームをワンクリックで自動入力するChrome拡張機能です。

## 特徴

*   **ワンクリック自動入力**: 拡張機能のアイコンを押してボタンをクリックするだけ。
*   **柔軟なマッチング**: サイトによって異なる「氏名」「住所」「電話番号」などの入力欄を、独自のスマートセレクター（ファジーマッチング）技術で自動判別します。
    *   `name="kname1"` や `id="zip1"` などの多様なパターンに対応。
    *   Reactなどのモダンなフレームワークで作られたサイトでも動作するように、イベント発火をシミュレート。
*   **セキュリティ**: データはブラウザのローカルストレージ（`chrome.storage.local`）のみに保存され、外部サーバには送信されません。
*   **設定機能**: ポップアップ画面からいつでもプロフィール情報を編集・保存できます。

## インストール方法

この拡張機能はストア公開されていません（開発者モード用）。以下の手順でインストールしてください。

1. このリポジトリをダウンロード（または `git clone`）します。
2. Chromeブラウザで `chrome://extensions/` を開きます。
3. 右上の「デベロッパーモード」をONにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックします。
5. ダウンロードした `lazy-entry` フォルダを選択します。

## 使い方

1. **初期設定**:
   - ブラウザ右上の拡張機能アイコン（パズルのピース）から「Lazy Entry」をクリックします。
   - ピン留めしておくと便利です。
   - ポップアップ画面で、あなたの情報を入力し「設定を保存」をクリックします。

2. **自動入力**:
   - 企業の採用ページや求人サイトの応募フォームを開きます。
   - 拡張機能アイコンをクリックし、「自動入力実行」ボタンを押します。
   - フォームが魔法のように埋まります！

## 対応している入力項目

*   **氏名**: 漢字（姓・名）、フリガナ（セイ・メイ）
*   **生年月日**: 年、月、日（分割フィールド対応）
*   **住所**: 郵便番号（ハイフンあり・なし・分割）、都道府県、市区町村、番地、建物名
*   **連絡先**: 自宅電話番号、携帯電話番号（分割対応）、メールアドレス（ID/ドメイン分割対応）
*   **学校情報**: 学校名、学部・学科、文理区分、入学・卒業年月、学校区分

## 技術スタック

*   Manifest V3
*   Vanilla JavaScript
*   Chrome Storage API

## 注意事項

*   万能ではありません。特殊な構造のサイトでは入力されない場合があります。
*   入力後は必ず内容を目視で確認してから提出してください。
